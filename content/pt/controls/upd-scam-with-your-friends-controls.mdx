## Teclas Padrão: Layout de Teclado e Mouse

Familiarizar-se com os comandos básicos é essencial antes de ajustar preferências avançadas. A configuração de teclado e mouse oferece o controle mais preciso para trocas rápidas de inventário, navegação em menus e comandos de reação rápida.

O layout padrão divide suas ações entre movimentação geral do personagem, manipulação ativa (inspecionar, negociar, pegar) e ações de meta-comunicação, como apertar para falar (push-to-talk) e sinalização com emotes.

| Categoria de Ação | Tecla Principal | Opção Secundária | Função no Jogo |
| :--- | :--- | :--- | :--- |
| **Movimentação** | W, A, S, D | Teclas de Seta | Movimentação multidirecional padrão |
| **Correr / Disparada** | Shift Esquerdo | Nenhuma | Acelera a velocidade de movimento durante fugas |
| **Interação Primária** | E | Clique Esquerdo do Mouse | Pegar itens, assinar acordos, confirmar trocas |
| **Inspeção Secundária** | Clique Direito do Mouse | Q | Inspecionar inventários de jogadores ou detalhes de itens |
| **Inventário / Esconderijo** | Tab | I | Abrir bolso pessoal de recursos ou inventário de golpes |
| **Largar / Rejeitar Item** | G | Backspace | Descartar item segurado ou largar mercadorias suspeitas |
| **Aperte para Falar (Voz)** | V | Botão 4 do Mouse | Abrir microfone para chat de voz por proximidade |
| **Ping / Sinalização** | Clique do Meio do Mouse | C | Destacar itens, jogadores ou objetivos |

| **Pausa / Menu do Jogo** | Escape | P | Abrir configurações do sistema, remapeamento de controles e áudio |

Ter a interação primária (`E`) e o descarte rápido (`G`) facilmente acessíveis evita atrasos fatais quando um acordo dá errado. Se você costuma largar itens valiosos acidentalmente, reposicionar a tecla de descarte para uma posição mais afastada dos dedos é uma recomendação popular da comunidade.

## Solução de Problemas: Bugs de Controle e Latência de Entrada

Após atualizações significativas, a experiência dos jogadores indica que as configurações de teclas podem ser redefinidas ou atrasos de comando podem surgir devido a limites de taxa de quadros em segundo plano ou conflitos de overlays.

| Problema | Causa Provável | Correção Recomendada |
| :--- | :--- | :--- |
| **Input Lag / Sensação de Atraso** | V-Sync ativado ou modo janela sem bordas | Mude para Tela Cheia Exclusiva; desative o V-Sync no jogo |
| **Teclas Redefinindo Sozinhas** | Arquivo de configuração como somente leitura ou conflito de sincronização na nuvem | Remapeie, salve, feche para a área de trabalho e reinicie o jogo uma vez |
| **Controle Não Responde** | Steam Input em conflito com drivers nativos | Ative/desative o Steam Input nas propriedades do jogo para cada controle |
| **Microfone Travado Aberto** | Modo alternar PTT ativado em vez de segurar para falar | Verifique Áudio/Controles e ative o modo "Segurar para Falar" |
| **Interação Registrando Duas Vezes** | Latência de debounce do switch do mouse ou atraso de repetição de tecla | Aumente a janela de debounce de entrada nas opções do jogo |

Se os seus comandos personalizados não forem registrados após a aplicação de um novo patch, verifique a integridade dos arquivos locais e redefina o perfil de controle para o padrão uma vez antes de reaplicar o seu layout preferido. Isso atualiza o esquema de configuração subjacente.

Remapeie a ação de largar ou descartar para uma tecla mais distante, como `X` ou `Backspace`, para eliminar de vez as quedas acidentais de itens durante as negociações.

### Como corrijo o input lag durante partidas multijogador com muitos jogadores?
