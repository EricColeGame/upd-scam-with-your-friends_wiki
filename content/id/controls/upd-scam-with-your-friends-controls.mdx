## Keybind Default: Tata Letak Keyboard dan Mouse

Membiasakan diri dengan input dasar sangat penting sebelum menyesuaikan preferensi lanjutan. Pengaturan keyboard dan mouse menawarkan kontrol paling presisi untuk pertukaran inventaris yang cepat, navigasi menu, dan respons reaksi cepat.

Tata letak standar membagi tindakan Anda antara pergerakan karakter umum, manipulasi aktif (memeriksa, berdagang, mengambil), dan tindakan meta-komunikasi seperti push-to-talk serta ping emote.

| Kategori Tindakan | Tombol Utama | Opsi Sekunder | Fungsi dalam Gameplay |
| :--- | :--- | :--- | :--- |
| **Pergerakan** | W, A, S, D | Tombol Panah | Pergerakan multi-arah standar |
| **Sprint / Lari Cepat** | Shift Kiri | Tidak ada | Mempercepat laju pergerakan saat melarikan diri |
| **Interaksi Utama** | E | Klik Kiri Mouse | Mengambil item, menandatangani kesepakatan, mengonfirmasi transaksi |
| **Pemeriksaan Sekunder** | Klik Kanan Mouse | Q | Memeriksa inventaris pemain atau detail item |
| **Inventaris / Penyimpanan** | Tab | I | Membuka kantong aset pribadi atau inventaris penipuan |
| **Jatuhkan / Tolak Item** | G | Backspace | Membuang item yang dipegang atau menjatuhkan barang mencurigakan |
| **Push-to-Talk (Suara)** | V | Tombol Mouse 4 | Membuka mikrofon untuk obrolan suara lokal |
| **Ping / Tanda Panggilan** | Klik Tengah Mouse | C | Menandai item, pemain, atau objektif |
| **Emote Cepat / Ejekan** | T | Y | Membuka roda ekspresi atau emote pengalih perhatian |
| **Jeda / Menu Game** | Escape | P | Membuka pengaturan sistem, pemetaan ulang kontrol, dan audio |

Memiliki interaksi utama (`E`) dan tombol buang cepat (`G`) yang mudah dijangkau mencegah keterlambatan fatal saat kesepakatan memburuk. Jika Anda terus-menerus menjatuhkan item bernilai tinggi secara tidak sengaja, memindahkan tombol buang ke posisi jari luar adalah rekomendasi komunitas yang populer.

### Cara Menyesuaikan Sensitivitas dan Deadzone

1. Buka **Options > Controls** dari lobi utama atau menu jeda.
2. Di bawah **Mouse Sensitivity**, sesuaikan rasio horizontal dan vertikal menjadi 1:1 untuk menghindari pelacakan vertikal yang lamban saat memeriksa bahaya ruangan.
3. Bagi pemain kontroler, turunkan **Stick Deadzone** ke 5%–8%. Ini memastikan respons pergerakan instan saat berlari menjauh dari rival yang marah.
4. Atur **Interaction Hold Time** ke minimum jika game memiliki perintah tahan-untuk-mengaktifkan; ini menghemat milidetik berharga pada setiap konfirmasi transaksi.

## Strategi Gameplay: Menggunakan Kontrol untuk Mengungguli Teman Anda

Kontrol dalam game penipuan bukan sekadar tentang bernavigasi di dunia game; kontrol adalah alat untuk perang psikologis. Bahasa tubuh, keraguan, dan gerakan tangan yang cepat dapat membocorkan niat Anda atau memancing pemain lain ke dalam perdagangan yang merugikan.

                 ▼
     [ Kunci Kesepakatan & Sprint ]

Ketika Anda memahami pengaturan waktu frame yang tepat dari input Anda, Anda dapat memanipulasi apa yang ditampilkan model karakter Anda kepada orang lain.

### 1. Pertukaran Cepat "Ghost Trade"
Dengan mengikat tombol penyimpanan ke tombol ibu jari mouse, Anda dapat menukar kontrak atau item asli dengan tiruannya tepat saat menekan tombol interaksi. Pemain yang membaca isyarat animasi standar akan melihat interaksi yang telah selesai sebelum menyadari bahwa slot inventaris mereka menerima barang tiruan.

### 2. Berpura-pura Pasif Melalui Free-Look
Dalam tata letak standar, menggeser kamera akan menggerakkan kepala karakter Anda. Dengan menahan tombol Free-Look atau Periksa yang telah ditentukan, Anda dapat memindai ruangan untuk melihat pemain yang mendekat tanpa memutar model karakter Anda secara kasat mata. Ini memancing lawan yang lengah untuk membisikkan kesepakatan rahasia dalam jangkauan pendengaran Anda.

### 3. Pelarian Cepat Saat Panik
Ketika tuduhan dilontarkan dan seisi lobi menjadi bermusuhan, penempatan jari default dapat menyebabkan Anda membuka inventaris secara tidak sengaja alih-alih berlari cepat. Memindahkan tombol penyimpanan menjauh dari Tab mencegah kesalahan klasik tersebut, memungkinkan Anda melompati rintangan dan melewati pintu dalam sekejap.

## Mengatasi Masalah Glitch Kontrol dan Latensi Input

Setelah pembaruan besar, pengalaman pemain menunjukkan bahwa konfigurasi keybind dapat tereset, atau kelambatan input dapat muncul akibat pembatasan frame-rate latar belakang atau konflik overlay.

| Masalah | Kemungkinan Penyebab | Perbaikan yang Disarankan |
| :--- | :--- | :--- |
| **Input Lag / Terasa Melayang** | V-Sync aktif atau mode jendela tanpa batas (borderless) | Beralih ke Exclusive Fullscreen; nonaktifkan V-Sync di dalam game |
| **Keybind Tereset** | File konfigurasi disetel ke read-only atau terjadi tabrakan sinkronisasi cloud | Atur ulang tombol, simpan, keluar ke desktop, dan mulai ulang game sekali |
| **Gamepad Tidak Responsif** | Steam Input bentrok dengan driver bawaan | Aktifkan/nonaktifkan Steam Input di properti game per kontroler |
| **Tombol Suara Terbuka Terus** | Mode alih (toggle) PTT aktif alih-alih tekan-untuk-menahan | Periksa Audio/Kontrol dan alihkan ke mode "Tahan untuk Bicara" (Hold to Talk) |
| **Interaksi Terdaftar Dua Kali** | Latensi debounce switch mouse atau delay pengulangan tombol | Tingkatkan rentang input debounce di pengaturan dalam game |

Jika binding kustom Anda gagal terdaftar setelah memasang patch baru, verifikasi file lokal Anda dan reset profil kontrol ke default sekali sebelum menerapkan kembali tata letak pilihan Anda. Tindakan ini akan menyegarkan skema konfigurasi dasarnya.

## Pertanyaan yang Sering Diajukan

### Apakah saya bisa memainkan UPD Scam With Your Friends dengan kontroler di PC?
Ya, game ini mendukung input gamepad bawaan untuk kontroler standar Xbox dan PlayStation, serta pemetaan ulang penuh melalui Steam Input. Anda dapat menyesuaikan sensitivitas stik, kurva respons pelatuk, dan tata letak tombol langsung dari opsi kontrol dalam game.

### Apa tata letak keybind yang paling andal untuk kontrol UPD Scam With Your Friends?
Sebagian besar pemain berpengalaman merekomendasikan untuk memetakan ulang interaksi ke `F`, penyimpanan ke `Q`, dan push-to-talk ke tombol samping mouse sekunder. Hal ini memastikan jari telunjuk dan jari tengah Anda didedikasikan khusus untuk pergerakan (`W`, `A`, `S`, `D`), sehingga Anda tidak pernah berhenti bergerak selama negosiasi yang sengit.

### Mengapa karakter saya terus menjatuhkan item secara tidak sengaja?
Tombol buang default (`G`) terletak tepat di sebelah tombol interaksi utama (`F` atau `E` tergantung pada pengaturan awal). Petakan ulang tindakan menjatuhkan atau membuang ke tombol yang jauh dari jangkauan biasa seperti `X` atau `Backspace` untuk sepenuhnya menghilangkan insiden menjatuhkan item yang tidak disengaja selama transaksi.

### Bagaimana cara mengatasi input lag saat sesi multipemain dengan banyak pemain?
Latensi input di lobi yang ramai biasanya berasal dari frame rate yang tidak dibatasi atau mode tampilan berjendela (windowed). Beralihlah ke Exclusive Fullscreen di pengaturan video, batasi frame rate Anda agar sesuai dengan refresh rate monitor Anda, dan pastikan polling rate periferal diatur ke 500Hz atau 1000Hz di perangkat lunak mouse Anda.
